# RNN Stock Price Prediction

This project is a Deep Learning case study using Recurrent Neural Networks (RNN) for stock price prediction.

## Technologies Used
- Python
- TensorFlow / Keras
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Project Overview
The model uses historical stock market data to predict future stock prices using RNN architecture.

## Features
- Data preprocessing
- Normalization
- RNN model training
- Prediction visualization
- Performance evaluation
